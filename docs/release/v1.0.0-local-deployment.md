# Local & Deployment Commands (Phase 48)

## Install

```
bun install
```

## Local `.env`

Copy `.env.example` to `.env` and fill in Supabase + provider values. Never
commit `.env`. For release provenance, additionally set:

```
VITE_BUILD_VERSION=1.0.0-beta.1
VITE_BUILD_ID=<ci-run-id>
VITE_GIT_COMMIT=<short-sha>
VITE_DEPLOYED_AT=<ISO-8601 UTC>
VITE_RELEASE_CHANNEL=CLOSED_BETA
VITE_DEPLOY_ENV=production
```

Any missing value renders as `NOT INJECTED` on `/status` — never a fake
timestamp or `dev`/`local`.

## Common commands

| Task | Command |
|------|---------|
| Dev server | `bun run dev` |
| Typecheck | `bunx tsgo --noEmit` |
| Tests | `bunx vitest run` |
| Production build | `bun run build` |
| Start production server | `bun run start` |
| Rollback | see `docs/release/v1.0.0-rollback.md` |

## Inject release metadata (CI)

Export the six `VITE_*` variables above before running `bun run build`. Vite
bakes them into the client bundle; the same values render on the public
`/status` page and the admin `/admin/system-status` console.

## External services required for full LIVE behavior

- Supabase (auth, database, RLS, pg_cron)
- Upstox (market data + option chain)
- CoinDCX (crypto + tokenized metal market data)
- Yahoo Finance (Gold/Silver ratio — GC=F, SI=F)
- Telegram Bot API (Morning Brief 08:15 IST)
- Razorpay (subscription webhooks — currently disabled on closed beta)

Modules without a connected provider render in RESEARCH / PROVIDER PENDING
state with a visible reason label.
